톡가계부 개인정보처리방침

시행일: 2026년 7월 12일

한 줄 요약 — 톡가계부는 결제 알림에서 금액과 가게 이름만 읽어 기기에 저장합니다. 알림 원문·개인 대화는 수집하지 않고, 광고·분석 도구도 쓰지 않습니다.

1. 수집하는 정보

  • 결제 알림 내용: 카드사·은행·간편결제 앱의 결제 알림에서 금액, 가게 이름, 시각을 추출해 기기에 저장합니다. 결제와 무관한 알림(메신저 대화 등)은 판별 즉시 폐기하며 저장하지 않습니다.
  • 사용자가 직접 입력한 내역: 직접 입력한 지출·수입, 분류, 예산.
  • 이름(별명): 가족 공유 시 표시할 별명 (예: 엄마, 아빠).

2. 알림 접근 권한을 쓰는 이유

결제 알림을 자동으로 가계부에 기록하는 것이 앱의 핵심 기능이기 때문입니다. 이 권한은 사용자가 설정에서 직접 허용해야 하며, 언제든 끌 수 있습니다. 권한을 꺼도 직접 입력 기능은 계속 사용할 수 있습니다.

3. 저장과 전송

  • 모든 데이터는 기본적으로 사용자 기기 안에만 저장됩니다.
  • 가족 공유를 켠 경우에만 지출 내역(금액·가게·분류·별명)이 암호화된 통신(HTTPS)으로 서버(Supabase)에 저장되어 같은 가족 코드를 가진 구성원끼리 공유됩니다.
  • 서버 데이터는 가족 코드를 아는 구성원 외에는 접근할 수 없도록 보호됩니다(행 수준 보안).
  • 카드번호·계좌번호·비밀번호는 수집하지 않으며, 알림 문구에 긴 숫자가 있으면 가리고 저장합니다.

4. 제3자 제공·광고

개인정보를 제3자에게 판매하거나 제공하지 않습니다. 광고 SDK, 분석(트래킹) 도구를 사용하지 않습니다.

5. 삭제

  • 앱에서 내역을 삭제하면 서버에서도 삭제됩니다.
  • 앱을 삭제하면 기기 데이터가 모두 삭제됩니다.
  • 가족 공유 데이터 전체 삭제를 원하시면 아래 이메일로 가족 코드와 함께 요청해주세요.
