# 직거래 · 컨설팅 시장 분리 계획 (10월 ~ 2월)

## 전제

직거래 시장과 컨설팅 시장은 **절대 섞지 않는다.**

| 구분 | 직거래 (DIRECT) | 컨설팅 (CONSULTING) |
| --- | --- | --- |
| 매물 | 공개 가능한 소형·저가·직접응대 가능 매물 | 비공개·고매출·고가·복잡한 매물 |
| 노출 | 직거래 사이트에 공개 | 비공개, 담당자 매칭 |
| 응대 | 점주 직접 | 담당자 개입 |
| 매수자 풀 | 소액 매수자 DB | 별도 비공개 매수자 풀 |
| 수익 | 무료 + 유료 자동매칭 (1월~) | 기존 수수료 |

## 시스템 규칙 (코드로 강제)

구현: `market/js/domain.js`, 테스트: `tests/domain.test.js`

1. 매물 하나는 `DIRECT` 또는 `CONSULTING` **둘 중 하나의 채널만** 가진다. (`assertChannelInvariant`)
2. 직거래 등록 매물 → 컨설팅 CRM 화면에 나타나지 않는다. (`consultingListings`)
3. 컨설팅 등록 매물 → 직거래 사이트에 노출되지 않는다. (`directListings`, `filterDirect`)
4. 채널 변경 → 기존 판매채널을 **종료한 뒤에만** 가능하다. (`canChangeChannel`, `changeChannel`)
5. 아래 기준 이상이면 직거래 버튼 자체를 막고 **"이 매물은 비공개 컨설팅 검토 대상입니다"** 로 보낸다. (`classifyListing`)
6. 직거래 자동매칭(및 향후 유료 매칭 상품)은 컨설팅 매물에 절대 적용하지 않는다. (`matchBuyersForListing`은 컨설팅 매물에 예외)

### 1차 분류 기준

직거래 가능 조건 (모두 충족해야 함)

- 공개 노출 가능
- 점주가 직접 문의 응대 가능
- 매각 사실이 주변에 알려져도 문제 없음
- 저~중매출, 낮은 권리금, 소액 창업자 대상

컨설팅 전용 조건 (하나라도 해당하면 직거래 차단)

- 비공개 요청
- 직원·고객에게 매각 사실 노출 곤란
- 본사·명의변경·계약구조가 복잡함
- 경쟁점 노출 위험이 큼
- 고액 투자자 대상
- 금액 기준 초과 (`THRESHOLDS`, 만원 단위)
  - 월매출 3,000 이상
  - 월순이익 700 이상
  - 권리금 5,000 이상
  - 총 양도가 10,000 초과

금액 기준은 초기값이며 `THRESHOLDS` 상수 하나로 조정한다.

### 11월: 직거래 매물 확보

컨설팅으로 받을 만한 매물은 절대 직거래로 유도하지 않는다.

1. 기존 탈락 매물: "컨설팅 방식으로 진행하기에는 규모가 작아서, 직거래 쪽으로 등록하시는 게 더 맞습니다."
2. 네이버 카페 직거래 매물 (이미 점주가 직접 공개 판매 중인 매물만): "사장님이 직접 판매하시는 방식은 그대로 두고, 저희 직거래 매물에도 무료로 추가 노출하실 수 있습니다."
3. SNS·블로그·지역 커뮤니티에 직접 "양도합니다"를 올린 점주.
4. 저가 매수자 DB에서 역으로 매물 확보: "현재 부산 5천 이하 음식점 찾는 매수자 있습니다. 직접 양도하실 사장님 모집합니다."

중개 영업처럼 보이지 않는 것이 핵심.

### 12월: 매수자 DB 확대

가치 제안 하나로 통일: **"찾아다니지 마세요. 조건만 등록하면 새 매물이 뜰 때 알려드립니다."**

콘텐츠 주제 예시 (모두 마지막 CTA는 "조건 등록해두면 맞는 매물 올라올 때 알려드립니다"):
3천만원으로 가능한 장사 / 5천만원 이하 실제 매물 / 보증금 포함 총 5천으로 가능한 업종 / 신규창업보다 양도가 싸지는 경우 / 매출 2천이면 실제 얼마 남나 / 월세 150 이하 매장 / 소자본 창업 실패하는 이유 / 프랜차이즈별 실제 창업비 / 1인 운영 가능한 업종

### 1월: 유료 구조

무료: 직접 등록, 직접 검색, 직접 연락.
유료 첫 상품 하나: **매수자 자동매칭 30일 5.9만 원**

- 기존 매수자 DB에서 조건 맞는 사람 자동 탐색

- 직거래 페이지 우선노출

컨설팅 매물에는 이 상품을 절대 적용하지 않는다.

## 컨설팅 시장의 위치

컨설팅을 "직거래보다 더 좋은 서비스"로 설명하지 않는다. 아예 다른 시장이다.

- 직거래: 공개해서 직접 찾는 시장
- 컨설팅: 공개하면 안 되는 매물을 비공개로 매칭하는 시장

컨설팅의 가치: 비공개 매물, 고매출 매장, 본사 정보, 실제 운영 데이터, 매도자 검증, 계약 조건 조정, 직원 브리핑, 비공개 매수자 DB.

## 콘텐츠 유입 후 분기

콘텐츠는 넓게(상권·브랜드·창업·장사·실제매출·실제비용·프랜차이즈·매물), 거래구조는 엄격하게 분리.

| 유입 콘텐츠 | 분기 |
| --- | --- |
| "5천으로 창업 가능한 업종" | 직거래 매수자 |
| "월매출 8천 카페 실제 수익" | 컨설팅 매수자 |
| "가게 양도할 때 직원 몰래 파는 법" | 컨설팅 매도자 |
| "수수료 없이 직접 가게 파는 법" | 직거래 매도자 |
